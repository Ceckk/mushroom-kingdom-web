# Mushroom Kingdom — web demo

Play it in your browser: https://ceckk.github.io/mushroom-kingdom-web/

Plant a spore, watch glowing threads spread through the dark forest, harvest mushrooms with a swipe and hire beetles to do it for you. Light up the whole forest to win.

This repository holds only the built game (a Unity Web player), published with GitHub Pages. Works on phones and desktop browsers.
